# Product Backlog

本文档是项目的全局产品 Backlog，维护 Epics / Features 两级索引。

> ID 命名与生命周期规则见 [ADR-003](../decisions/ADR-003-naming-convention.md)。
> **核心规则**：所有层级 ID（Epic / Feature / US）一经分配永不复用，被废弃的标记 `(retired)` 留 tombstone。
