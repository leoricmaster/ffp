## 关键实现要点

- **Argon2id**：m=19MiB, t=2, p=1, hashLength=32（默认 salt 16B）
- **JWT HS256**：accessToken 15min（payload 含 userId/familyId）；refreshToken 7d
- **HKDF-SHA256**：`deriveTokenHash(JWT_SECRET, tokenFamilyId, refreshToken)` → 64-char hex
- **5min IdempotencyStore**：Map-based TTL，key=`register:{email}`
- **事务原子性**：user + family + member + 14 分类在 in-memory store 中顺序写入；任何异常调用 `familyRepository.rollbackRegistration` best-effort 清理
- **错误码映射**：Zod invalid_type → MISSING_REQUIRED_FIELD；privacyPolicyAccepted → INVALID_PRIVACY_CONSENT；password → WEAK_PASSWORD；email → INVALID_FORMAT
- **Cookie**：httpOnly; SameSite=Lax; Path=/api/v1/auth; Max-Age≈7d; Secure 取决于 COOKIE_SECURE
- **限流**：`ipKeyGenerator` 处理 IPv6；IP 20/h + email 5/day
