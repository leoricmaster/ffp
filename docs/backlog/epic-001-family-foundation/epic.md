# Epic-001：家庭财务基础

## 目标

用户完成注册后，能在 3 分钟内记录第一笔家庭支出。

## 背景

FFP 的核心价值假设是"家庭愿意协作记录和分析财务数据"。本 Epic 是验证该假设的最小可行路径，覆盖从"零"到"第一笔记录"的完整用户旅程。

## 范围

### 包含

- 用户通过邮箱+密码注册账户
- 注册后系统自动创建默认家庭
- 用户登录系统
- 用户记录一笔支出（金额、分类、日期、描述）
- 用户查看支出记录列表

### 不包含

- 邮箱验证（PENDING → ACTIVE 状态机简化，注册即 ACTIVE）
- 家庭成员邀请与管理
- 收入记录
- 资产/负债记录
- 数据分析与可视化
- 分类体系的自定义配置（使用系统预设分类）

## 关联 Feature

| Feature | 名称 | 状态 | 说明 |
|---------|------|------|------|
| ft-001 | 用户注册与家庭创建 | planned | 身份与家庭基础设施 |
| ft-002 | 记录支出 | planned | 核心财务记录功能 |

## 成功标准

- 新用户从打开应用到记录第一笔支出的平均时间 < 3 分钟
- 系统预设的支出分类覆盖 80% 以上常见家庭支出场景
